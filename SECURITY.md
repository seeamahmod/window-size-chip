# Security Policy

## Supported versions

Only the latest version on the `main` branch gets security fixes.

| Version | Supported |
| ------- | --------- |
| Latest (`main`) | Yes |
| Older versions | No |

## Reporting a vulnerability

Please **don't open a public issue** for security problems.

Report it privately instead:

1. Go to the [Security tab](https://github.com/seeamahmod/window-size-chip/security) of this repository.
2. Click **Report a vulnerability**.
3. Describe the problem, the steps to reproduce it, and what an attacker could do with it.

You can expect a first reply within 7 days. Once the problem is confirmed, a fix
will be released as soon as possible and you'll be credited in the advisory if
you'd like.

## Scope

This extension runs entirely in your browser. It has no server, collects no
data and makes no network requests of its own. Things worth reporting include:

- A website being able to read or change the extension's data, or trigger its actions.
- The extension exposing page content to other sites.
- Permissions being used beyond what the extension needs.
