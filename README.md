# Window Size Chip

A tiny Chrome extension that shows the live size of your browser window.

- **Toolbar badge** – the width shows on the extension icon; hover it for `width × height`.
- **On-page chip** – a floating pill in the corner of each page shows
  `window W × H` plus the `viewport W × H`, updating live as you resize.
  - Click the chip to move it to another corner.
  - Click the toolbar icon to hide/show the chip everywhere.

## Install (unpacked)

1. Open `chrome://extensions`.
2. Turn on **Developer mode** (top right).
3. Click **Load unpacked** and pick this folder.
4. Pin the extension (puzzle icon → pin) so it sits next to the other toolbar chips.

The chip doesn't appear on `chrome://` pages or the Chrome Web Store; Chrome blocks extensions there.
